# zarondo.com

The holding page for Zarondo Games, served by GitHub Pages at https://zarondo.com.

- `index.html` and `style.css` are the whole page.
- `assets/` holds the logo, icons, link preview picture and the Quicksand font.
- `CNAME` tells GitHub Pages which domain to serve.

The logo files are generated in the game repository, under
`docs/concept-art/brand/studio`. Copy new versions from there; do not edit them here.

The social icons are from Simple Icons (simpleicons.org), released under CC0.
Quicksand is under the SIL Open Font Licence; see `assets/quicksand-licence.txt`.
